# CMS v1.0.14 — Production UI hardening (P4 RC)

This patch follows the first production deployment of CMS v1.0.13.

## Storefront Merchandising layout

- The homepage hero artwork field now spans the full two-column editor width.
- Primary and secondary CTA controls remain paired on the row below.
- Top-level subsection headers now receive consistent spacing when they follow a card, preventing section titles/actions from visually colliding with the preceding table/card.

## Production frontend build safety

The canonical non-secret `.env.production` is now included with:

```text
VITE_NEXTF_ENVIRONMENT=production
VITE_NEXTF_BACKEND_MODE=production-api
VITE_NEXTF_API_BASE_URL=https://cms-api.nextf.lk
```

Vite loads this automatically for `npm run build` / `npm run deploy`, preventing production Pages deployments from silently falling back to the local prototype identity/environment. Secrets remain in Cloudflare Worker secrets and are not stored in this file.

## Deployment

CMS frontend-only deployment is sufficient for this patch unless the API source is changed independently:

```powershell
npm ci
npm run build
npm run check:gaming-storefront-merchandising
npm run check:release-hygiene
npm run deploy
```

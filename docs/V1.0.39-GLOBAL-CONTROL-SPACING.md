# NEXT F CMS V1.0.39 — Global Control Spacing

This release standardizes horizontal insets for the shared CMS control system.

## Changes

- Shared text inputs use a 12px inline inset.
- Shared custom selects use a 12px start inset and reserve 40px at the end for the chevron.
- The select chevron sits 11px from the control edge instead of 5px.
- Select menu options use the same 12px inline spacing.
- Toolbar, catalog and promotions search shells use the same shared control inset.
- Modal, table, payment, supplier and commerce behavior is unchanged.

## Regression guard

Run `npm run check:global-control-spacing`.

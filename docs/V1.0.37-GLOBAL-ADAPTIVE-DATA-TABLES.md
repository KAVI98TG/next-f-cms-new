# NEXT F CMS V1.0.37 — Global Adaptive Data Tables

## Scope

This release updates the shared `DataTable` component and table CSS only. It does not change Worker APIs, D1 schema, contracts, commerce calculations, permissions, payment logic, or supplier behavior.

## Design rule

- Tables use intrinsic content sizing instead of page-specific fixed pixel columns.
- The first non-utility data column is the flexible anchor by default.
- `select`, `action`, and `actions` columns stay content-sized.
- Other columns stay content-sized and do not wrap badges/buttons/status controls.
- Headers remain single-line.
- Wide datasets scroll horizontally instead of wrapping operational labels into unreadable stacks.
- A column can explicitly opt into `sizing: "grow"` or `sizing: "content"`.

## Customer 360 result

The Customer column remains the flexible identity column. Account, Orders, Net spend, Last purchase, Marketing, Lifecycle and View consume only the width their content needs. `Google verified` remains on one line.

## Compatibility

All former `width: "Npx"` declarations were removed from `DataTableColumn` definitions. The shared table wrapper remains horizontally scrollable for narrow screens and large operational datasets.

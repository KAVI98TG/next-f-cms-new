# V1.5.0 multi-Site analytics rollout (implementation in progress)

This is a rollout record, not a production release claim. CMS v1.0.64 remains the deployed baseline. Contract Registry V1.5.0 / Phase 42 is the target for property management; the CMS production collector remains on its V1.4.0 single-Site route until cutover.

## Implemented locally

- The main Site manifest now pins V1.5.0 after explicit user approval. Contracts CLI validation passed with zero errors and warnings, and the Site production check passed. The main Site has not been redeployed.
- CMS migrations `0003_tracking_properties.sql`, `0004_tracking_configuration_records.sql`, and `0005_tracking_write_preconditions.sql` add canonical Site evidence, property, environment binding, configuration/policy records, and atomic precondition enforcement. They have been applied locally only.
- The CMS Worker implements organization-scoped property discovery, validated-manifest provisioning, If-Match reconciliation and suspension, exact Site/environment/origin routing, public-safe bootstrap, audited mutations, and lifecycle event outbox retry. The legacy collector remains behind a default-off property-routing switch.
- The CMS Analytics page can select an authorized Site property and environment. It retains the existing honest aggregate-only dashboard; it does not claim unique users, sessions, attribution, or revenue.
- A two-Site integration fixture uses the real main Site manifest plus a non-production test Site. It tests separate properties, organization and origin isolation, environment gating, idempotence, If-Match, suspension, and recovery after a simulated lifecycle Queue outage. No second real Site has been provisioned.
- The verified production staff binding received the user-approved `platform.sites.view` and `marketing.tracking.manage` grants. No other staff account was changed.

## Scope and privacy

Property data derives from server-held, validated Site Manifest evidence, not a browser-supplied origin. The second Site is test-only. Raw tracking observations remain bounded by policy and do not include form contents or contact details. Optional consent remains fail closed. Each Site/environment must have its own exact origin and binding; preview/staging is not a production analytics alias.

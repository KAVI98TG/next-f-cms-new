# CMS v1.0.15 — Storefront search & save-state UX (P4 RC)

## Changes
- Replaces the Homepage Hero product dropdown with the reusable `SearchSelectInput`.
- Search matches product display/name, game family, category and product ID.
- Keeps the explicit storefront save boundary; hero/section draft edits are not silently auto-saved.
- Adds clear `Unsaved changes` / `All storefront changes saved` state.
- Disables Save changes when the durable storefront already matches the draft.
- Warns before browser/tab exit while storefront changes are unsaved.
- Retains v1.0.14 production `.env.production` defaults and layout hardening.

# CMS v1.0.29 — Promotions campaign control center

## Scope

Frontend-only redesign of **Gaming Store → Promotions & Campaigns**. Existing Gaming promotion documents, staff API operations, commerce bridge credentials, pricing safeguards, redemption accounting and immutable order discount snapshots are unchanged.

## Campaign workspace

- compact overview for Active, Scheduled, Draft, Redemptions and Discount granted
- status views for All, Active, Scheduled, Draft, Paused, Ended and Archived
- search by campaign name, coupon code or campaign ID
- visual campaign cards with discount, scope, schedule, margin floor, usage and recorded discounted sales
- quick Edit, Duplicate, Pause and Activate actions using the existing canonical update command
- campaign-wide redemption progress when a maximum limit exists
- explicit empty state with a primary Create campaign action

## Campaign builder

Six-step campaign workflow:

1. Basics — name, status, Coupon code or Automatic campaign
2. Discount — percentage/fixed-LKR discount and minimum spend
3. Scope — canonical Product IDs and Offer IDs
4. Schedule — Starts at / Ends at
5. Limits & safety — Maximum redemptions, Per-customer limit and Campaign Margin floor LKR
6. Review — final canonical rule summary before create/update

The UI does not invent unsupported campaign types. Customer segments, category campaigns and first-order targeting are not exposed because those dimensions are not part of the current canonical promotion contract.

## Safeguards

The Gaming API remains authoritative. Discounts cannot bypass margin protection; eligibility is rechecked during quote/checkout and immutable discount snapshots remain attached to created orders.

## Deployment

CMS frontend only. No CMS API, Gaming API, D1 migration, Gaming storefront deployment or new secret is required.

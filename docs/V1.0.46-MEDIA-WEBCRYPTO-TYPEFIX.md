# NEXT F CMS v1.0.46 — Media WebCrypto Type Fix

## Problem

The v1.0.45 full package passed the source-level Media checks but failed the Worker TypeScript compiler at `crypto.subtle.importKey()` because TypeScript 5.8 can type a `Uint8Array` view as backed by `ArrayBufferLike`, which also permits `SharedArrayBuffer`, while WebCrypto requires a `BufferSource` backed by `ArrayBuffer`.

## Fix

The Media AWS SigV4 HMAC helper now copies key bytes into a newly allocated `ArrayBuffer` and passes that `ArrayBuffer` to WebCrypto. Runtime signing semantics are unchanged.

## Scope

CMS only. No Gaming change, D1 migration, secret rotation, Media schema change, or R2 configuration change.

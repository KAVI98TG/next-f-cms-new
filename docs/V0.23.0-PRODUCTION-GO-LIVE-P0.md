# V0.23.0 — Production Go-Live P0

P0 prepares the main NEXT F CMS frontend for deployment at the root of `https://cms.nextf.lk/` without changing the evidence-gated production backend boundary.

## Completed in P0

- Root-path deployment: Vite, router, brand assets and application navigation no longer depend on `/admin/`.
- SPA fallback for Cloudflare Pages/static hosting via `public/_redirects`.
- Global Light / Dark / System theme architecture with persisted browser preference.
- System theme tracks OS changes at runtime; initial head bootstrap prevents avoidable theme flash.
- Theme control is available globally from the top bar and explicitly from Platform → Settings.
- Light-theme design tokens cover surfaces, borders, text, accents, statuses, overlays, scrollbars and shadows used by shared components.
- Production frontend environment example added for `cms.nextf.lk`; the API Worker hostname remains an explicit deployment-time value rather than an invented DNS assumption.
- Release metadata aligned at V0.23.0.

## Boundary intentionally unchanged

P0 does not claim production V1.0. Core business persistence, production staff handlers, Cloudflare Access identity binding, live D1/R2/Queue deployment and acceptance evidence remain later go-live phases.

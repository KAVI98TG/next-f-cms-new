# V1.0.36 — Gaming Finance & Reconciliation UX

This release replaces the card-heavy Gaming finance screen with a finance command-center layout while preserving the existing live commerce data model and CSV export.

## UI changes

- Consolidates six oversized KPI cards into one money-flow view and one compact reconciliation snapshot.
- Shows the relationship between gross collections, refunds, net sales, net operating cost and estimated margin.
- Keeps supplier cost, gateway fees and recoveries visible without dedicating a full card to each value.
- Combines order economics and refund records into a single tabbed ledger workspace.
- Uses compact, explanatory empty states instead of rendering two large empty tables.
- Adds a visible refresh control next to CSV export.
- Keeps all status, data and permission boundaries unchanged.

## Runtime impact

Frontend-only. No D1 migration, Worker API, contract, payment, refund, supplier, or finance calculation changes are introduced.

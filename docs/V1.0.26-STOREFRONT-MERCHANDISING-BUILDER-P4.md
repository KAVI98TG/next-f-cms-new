# CMS v1.0.26 — Storefront Merchandising builder UI

## Scope

Frontend-only redesign of **Gaming Store → Storefront**. The canonical storefront, game-family, product and NEXT F Media contracts remain unchanged.

## UX changes

- compact storefront status strip for connection, homepage sections, artwork coverage and featured products
- split Hero Builder with content controls on the left and an always-visible customer preview on the right
- hero preview uses the production fallback order: hero override → family hero → family card → product artwork → styled fallback
- one explicit Saved / Unsaved storefront state; Save changes only appears when the storefront draft is dirty
- Homepage Sections render as visual merchandising cards with quick visibility and up/down ordering controls
- section modal edits apply to the storefront draft instead of persisting separately
- Game-family artwork is now a searchable/filterable visual card workspace with artwork state, product count and category colors
- discovered family persistence action appears only when new families actually need to be registered
- production Open storefront action remains connected to the configured Gaming storefront
- responsive desktop/tablet/mobile layouts

## Architecture unchanged

- supplier sync remains supply-fact authority only
- storefront merchandising remains NEXT F-owned presentation state
- artwork remains HTTPS-only and NEXT F Media-compatible
- no CMS API deployment, Gaming deployment, D1 migration or new secret is required

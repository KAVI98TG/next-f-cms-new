# V0.2.0 Platform Core

This release converts the V0.1.0 shell into a working platform administration layer.

## Functional modules
- Platform Dashboard
- Users
- Roles & Permissions
- Audit
- Notifications
- Integrations
- Infrastructure Readiness
- Health
- Settings

## Development data model
All V0.2.0 records use browser-persistent local storage through a dedicated Platform store. This allows the CMS to be built and tested before production infrastructure is selected and wired.

## Identity boundary
Platform users are staff/admin identities only. NEXT F Digital clients, Gaming Store customers and NEXT F Software customers belong to their own business-domain models.

## Production boundary
No production database, object storage, worker binding, runtime secret or deployment configuration is included in this release.

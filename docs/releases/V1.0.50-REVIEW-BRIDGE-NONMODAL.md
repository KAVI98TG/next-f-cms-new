# NEXT F CMS v1.0.50 — Review Bridge + Non-modal Moderation

> Historical release record. For the current v1.0.55 release, use the dedicated Reviews credential and rollout guidance in `V1.0.52-REVIEWS-BRIDGE-RECOVERY.md`; do not repeat the v1.0.50 commerce-token migration.

## Fixes

- Customer Reviews now use the established `GAMING_CMS_COMMERCE_TOKEN` bridge, matching their storefront/trust publishing role instead of depending only on the operations credential.
- Rejection moderation is inline inside the review card; no review moderation modal is rendered.
- Status filtering uses explicit NEXT F segmented controls instead of a native/select dropdown.
- Retry remains available when the bridge is unavailable.
- Existing review-decision idempotency isolation remains unchanged.
- Preserves v1.0.48 global overlay focus stability and v1.0.49 build-contract corrections.

## Deployment

Gaming API v1.8.25 must be deployed first so both old operations-auth CMS calls and new commerce-auth CMS calls are accepted during rollout. Then deploy CMS API v1.0.50 and CMS frontend v1.0.50. No D1 migration.

# NEXT F CMS v1.0.64 - Analytics Decision Dashboard

## Release relationship

- Canonical parent: v1.0.63
- Contract Registry target: v1.4.0 / Phase 41
- Release date: 2026-09-28
- Deployment scope: Cloudflare Pages frontend only

## Outcome

The Platform Analytics page now presents the real first-party event aggregates as an operational analytics dashboard instead of a collector-status page. It uses the existing permission-controlled reporting and health APIs and does not introduce a parallel analytics model.

## Dashboard capabilities

- range-aware KPIs for `page.viewed`, `cta.clicked`, `form.started` and `form.submitted`;
- an SVG event trend built from canonical hourly aggregates;
- an event-progression funnel and event mix that are explicitly described as event ratios, not unique-user conversion;
- collection health, accepted rate, consent-restricted count, rejected/schema-error count, SDK contract version and last-event freshness;
- hourly event detail for audit and operational diagnosis;
- clear empty, loading and error states;
- responsive layouts for desktop, tablet and mobile.

## Measurement and privacy boundaries

- No unique-user, session, source-attribution, revenue or user-level conversion metric is inferred from data the report does not contain.
- The funnel compares aggregate event counts and may include repeated events from the same visitor.
- Form contents, contact details, credentials and secret values are not displayed or introduced into tracking.
- Consent-restricted events remain visible only as aggregate pipeline quality evidence.

## Infrastructure impact

- No D1 migration.
- No Worker/API contract change.
- No Queue, binding, route or custom-domain change.
- No new secret.
- No production analytics data mutation.

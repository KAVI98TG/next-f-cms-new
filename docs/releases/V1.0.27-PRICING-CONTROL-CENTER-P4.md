# CMS v1.0.27 — Pricing control center UI

## Scope

Frontend-only redesign of **Gaming Store → Pricing & Safeguards**. The existing canonical FazerCards pricing document, D1 persistence, server-side checkout recalculation, permissions, and supplier-secret boundary remain unchanged.

## UI and workflow changes

- compact pricing overview for FX, pricing mode, retail target and supplier state;
- pricing policy grouped into Core pricing and Fees & rounding;
- explicit Saved / Unsaved pricing state;
- Save pricing policy is enabled only when the policy is valid and changed;
- Discard restores the persisted pricing policy;
- refresh cannot overwrite an unsaved draft;
- browser unload protection while pricing changes are unsaved;
- live operator simulator for an example USD supplier cost;
- preview shows converted cost, protected profit target, gateway fee, fixed fee, estimated profit, effective margin, rounding and customer retail estimate;
- simulator is explicitly non-authoritative: checkout remains server-side authority;
- compact production safeguards panel explains D1 authority, server recalculation, Worker-only supplier credentials and no-resync markup behavior.

## Deployment

CMS frontend only. No CMS API, Gaming API, Gaming Store frontend, D1 migration, or new secret is required.

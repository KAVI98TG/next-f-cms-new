# CMS v1.0.16 — Game-family filtering UX (P4 RC)

## Scope

Improves Gaming Store → Storefront → Game-family artwork for large catalogs.

- Adds text search across family name, slug and derived product category.
- Adds category filtering using canonical product kinds: topup, gift_card, game_key, steam, telegram, subscription and other.
- Shows per-category family counts.
- Adds card-artwork configured/missing filtering.
- Adds enabled/disabled filtering.
- Shows filtered/total family count and category context on each family row.
- No Gaming API, D1 schema, permission or storefront contract changes.

## Deployment

Frontend-only CMS hotfix. Build and deploy CMS Pages; the CMS API and Gaming Store/API do not need redeployment.

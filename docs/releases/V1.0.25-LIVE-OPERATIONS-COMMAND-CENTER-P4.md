# CMS v1.0.25 — Live Operations command center UI

## Scope

Frontend-only redesign of Gaming Store Live Operations. Existing Gaming API commands, permissions, D1 data, payment/refund/risk/fulfillment/notification boundaries, and audit behavior are unchanged.

## UI changes

- compact operational status strip for active orders, payment review, fulfillment attention, risk holds, refunds, notifications, and net sales
- all-clear / needs-attention banner with queue shortcuts
- queue-specific filters alongside global search
- denser sticky work-queue tables with contextual empty states
- recent operational activity feed outside the raw Events queue
- command bridge and payment-provider readiness moved into collapsible System diagnostics
- responsive layout for narrow screens

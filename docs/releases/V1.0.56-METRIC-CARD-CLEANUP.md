# NEXT F CMS v1.0.56 — Metric Card Cleanup

Canonical parent: **v1.0.55**. Frontend-only UI cleanup; no D1 migration, Worker contract change, binding change or new secret.

## Change

The shared `MetricCard` contract is simplified globally to **label + value + icon**. The generic footer/detail/trend area is removed from the shared component and from every existing `MetricCard` usage across Platform, NEXT F Digital, Website Platform, Gaming Store and Software.

This removes repeated or explanatory microcopy such as zero-state restatements, definitions and static helper lines under metrics. Operational detail that genuinely matters belongs in the relevant table, status badge, alert, workflow panel or action confirmation instead of a summary-card footer.

## Global styling

- removed `.metric-card__footer`;
- removed `.metric-card__trend` and direction styles;
- reduced the default shared metric-card minimum height from 148 px to 118 px;
- removed bottom spacing reserved for the old footer;
- compact metric layouts keep their existing responsive grid behavior.

## Prevention

`npm run check:ui-hygiene` now fails if a `MetricCard` receives `detail` or `trend` props, or if the shared component reintroduces the old footer contract. The CMS UI content standard now states that metric cards contain only label, value and optional icon.

## Scope

No business calculation, metric value, permission, API call, data source or production integration is changed. Only secondary metric-card presentation copy and the unused footer contract are removed.

# CMS v1.0.21 — Catalog control-center refresh

The canonical Gaming Catalog now scales to hundreds of products and thousands of offers/routes without row-by-row administration.

## Operator workflow

- Task-based product views: all, needs attention, public, featured, hidden.
- Search canonical product names, families, slugs and IDs.
- Filter by canonical product kind, offer-count band and routing health.
- Offers and supplier-routing tabs have their own status filters.
- Bounded 50/100/200 row pagination with sticky headers.
- Row selection supports page selection and select-all-filtered.
- Bulk product public/hidden and featured/unfeatured changes.
- Bulk offer public/hidden changes.
- Bulk supplier-route enable/disable changes.
- Bulk changes update the canonical durable document once, then flush through the production write boundary.

The existing single-record editors remain available for deep merchandising, pricing and route edits. No legacy v0.5 Gaming catalog is reintroduced.

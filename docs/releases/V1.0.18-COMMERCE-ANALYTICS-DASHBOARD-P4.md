# CMS v1.0.18 — Commerce Analytics dashboard refresh

Frontend-only P4 UX release for Gaming Commerce Analytics.

## What changed

- Replaced the flat analytics stack with a decision-dashboard hierarchy.
- Added a compact four-KPI overview strip.
- Reworked Customer Journey into a numbered funnel with clearer stage conversion and coverage state.
- Added a daily multi-series commerce pulse using the existing canonical `daily` analytics dataset.
- Grouped risk, notification, payment-verification, fulfillment, refund and margin health into one compact Operations panel.
- Added inline conversion progress indicators to product and supplier performance tables.
- Improved responsive layouts for tablet and mobile widths.
- No analytics API, event schema, permission, finance boundary or data-retention changes.

## Deployment

This is a CMS frontend-only release. The CMS Worker/API does not need to be redeployed.

```powershell
npm ci
npm run build
npm run check:gaming-analytics
npm run check:release-hygiene
npm run deploy
```

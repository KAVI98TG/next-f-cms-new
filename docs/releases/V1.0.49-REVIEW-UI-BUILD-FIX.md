# NEXT F CMS v1.0.49 — Review UI Build Fix

## Problem

The v1.0.47 customer-review moderation page used two prop names that do not match the shared CMS component contracts:

- `ToastInput` supports `description`, not `message`.
- `SectionHeader` supports `action`, not `actions`.

This caused the production frontend build to stop with `TS2353` and `TS2322` errors.

## Fix

`ReviewsPage.tsx` now uses the shared CMS contracts exactly:

- moderation success/error toasts use `description`;
- the Refresh button is supplied through `SectionHeader.action`.

No review workflow, API behavior, moderation semantics, D1 schema, or storefront behavior changed.

## Included previous fixes

This full release is based on CMS v1.0.48, so it retains the global Modal/Drawer focus-stability fix in addition to the v1.0.47 storefront carousel and review moderation work.

## Deployment

Frontend-only fix. No D1 migration and no CMS API deployment are required.

```powershell
npm ci
npm run check:review-ui-build-contract
npm run check:review-moderation
npm run check:overlay-focus
npm run build
npm run deploy
```

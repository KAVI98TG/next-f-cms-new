# V0.3.0 Digital Core

## Objective
Create the first complete NEXT F service-business vertical on top of the clean SaaS foundation.

## Implemented lifecycle

```text
Lead -> Opportunity -> Proposal -> Client -> Invoice -> Project
```

The lifecycle is not a collection of disconnected screens. Each handoff creates or updates the next business record in the Digital domain repository.

## Sales
- Create leads.
- Capture contact, company, source, interested service and estimated value.
- Qualify a lead into an opportunity.
- Track opportunity stage, probability, close date and next action.
- Create and send a proposal from an opportunity.
- Accept a proposal and convert it into operations.

## Conversion behavior
Accepting a proposal:
1. Marks the proposal accepted.
2. Marks the opportunity won.
3. Creates or links a client.
4. Creates an invoice.
5. Creates a planned project using the selected service template.
6. Writes Digital activity.
7. Writes a Platform audit event.

## Billing behavior
A linked invoice can be marked paid locally. If its project is still planned, payment activates that project.

## Project behavior
- Project templates come from service definitions.
- Milestones can be toggled complete.
- Milestone completion calculates project progress.
- 100% progress moves work into `awaiting_client`.
- Client approval completes the project.

## Development data
All Digital records persist in browser `localStorage` through the V0.3.0 domain store. Production storage remains deliberately deferred.

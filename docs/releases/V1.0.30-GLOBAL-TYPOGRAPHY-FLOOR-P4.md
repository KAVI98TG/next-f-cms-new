# CMS v1.0.30 — Global 10px typography floor

This frontend-only P4 release standardizes the minimum readable UI font size across the CMS and embedded Gaming UI.

## Changes

- Raised every 8px/9px `font-size` declaration in `src` to 10px.
- Added `--text-min: 10px` to the global design tokens.
- Added `check:font-floor`, which scans CSS and inline UI font sizes and fails if a future change introduces text below 10px.
- Existing spacing, icons, control dimensions, and layout measurements are unchanged.

## Scope

64 sub-10px declarations were corrected: 63 in shared CMS component styles and 1 in the embedded Gaming public stylesheet.

No API, D1 schema, secret, Gaming API, or commerce behavior changes are included.

# NEXT F CMS v1.0.62 - Form and Content Clarity

Canonical parent: **v1.0.61**. Frontend/Pages-only UI cleanup. No D1 migration, Worker/API contract change, binding change, or new secret.

## Changes

- stabilizes shared form-field sizing so an input no longer stretches when its neighboring field contains uploads or additional controls;
- adds deliberate full-width rows for long modal controls and multi-item pickers;
- moves the product editor's `Use supplier name` action into the field header;
- cleans the homepage-section editor layout so manual product selection has a full-width workspace and `Maximum products` pairs with `Source`;
- cleans the hero-slide editor layout so description and media controls use full-width rows while CTA fields remain paired;
- changes pricing-mode labels to concise parenthetical copy;
- removes em dash and en dash characters from TypeScript/TSX UI content and adds a regression guard so they do not return;
- updates the permanent CMS UI content standard with punctuation and modal-form layout rules.

## Validation

Static regression **71/71 passed** and the targeted release gate passed during packaging. The package remains a candidate until `npm run release:finalize` completes the frontend production build and Worker/API typecheck.

## Deployment

Pages/frontend only after finalization:

```powershell
npm ci
npm run release:finalize
npm run deploy
```

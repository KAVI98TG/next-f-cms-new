# NEXT F CMS v1.0.53 — Reviews Workspace UI

Canonical parent: **v1.0.52**.

## Changes

- Refreshes the four summary cards, moderation queue header, status filters and empty state.
- Explains the verified-purchase review flow in the empty queue and retains a compact staff-policy reminder.
- Preserves inline approve/reject actions, non-modal moderation, explicit loading/error/empty states and the dedicated review API bridge.

This is a CMS Pages frontend release. No Worker change, new secret or D1 migration.

## Follow-up

The first deployed layout still lacked the shared CMS page gutters because Reviews used a `page-stack` wrapper instead of the standard `page` wrapper. v1.0.54 corrects that spacing regression.

# CMS v1.0.20 — Commerce dashboard command-center refresh

## Scope
Frontend-only redesign of the production Gaming Store dashboard. No API, D1, secret, or Gaming Store deployment changes are required.

## Changes
- Replaced the oversized four-card production summary with a compact five-KPI strip.
- Added a dedicated Needs Attention panel with a compact all-clear state.
- Added operational readiness rows for supplier, payment review, fulfillment, risk holds, and notifications.
- Added a 30-day conversion snapshot using canonical Gaming Analytics funnel data.
- Reworked the activity feed and groups noisy product-view and supplier events.
- Added quick actions to Live Operations, Analytics, Support, Promotions, and Suppliers.
- Added responsive command-center CSS for desktop, tablet, and mobile.

## Data authority
The production dashboard continues to read only canonical Live Operations and Analytics snapshots. Retired `nextf.v0.5.gaming.*` state is not reintroduced.

## Deployment
CMS frontend only:

```powershell
npm ci
npm run check:gaming-dashboard
npm run check:gaming-build-contract
npm run build
npm run deploy
```

No CMS API deployment is required.

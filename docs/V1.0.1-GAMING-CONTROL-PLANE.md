# V1.0.1 — Gaming production control plane

The CMS now controls the live FazerCards supplier and pricing configuration used by `gaming-api.nextf.lk`.

## What operators can manage in CMS

**Gaming Store → Pricing & Safeguards**

- pricing mode;
- USD → LKR conversion;
- markup percent;
- payment/gateway fee percent;
- minimum profit LKR;
- fixed fee LKR;
- price rounding.

**Gaming Store → Suppliers**

- enable/disable FazerCards;
- API base URL (non-secret);
- catalog families;
- maximum categories per sync;
- auto-publish products/offers;
- supplier health/balance;
- catalog preview;
- production catalog sync;
- latest sync result/error.

## Secret boundary

The FazerCards API key remains an encrypted secret on the `nextf-gaming-api` Cloudflare Worker. The CMS browser never receives it. The supplier-admin token also remains outside the browser.

## Control channel

CMS writes audited, Access-protected staff-state documents into the shared production D1 database. The Gaming Worker reads those documents and processes queued health/preview/sync actions from its scheduled trigger. This keeps the CMS as the business control plane without turning the browser into a supplier API client.

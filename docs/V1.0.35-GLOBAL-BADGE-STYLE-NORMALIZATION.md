# NEXT F CMS v1.0.35 - Global Badge Style Normalization

## Scope

This release standardizes the shared CMS `Badge` visual language without changing commerce, supplier, payment, media, or contract behavior.

## Changes

- Shared status/category badges use 12px semibold text, 24px minimum height, 9px horizontal padding, 6px radius, and normal casing.
- `operation-section__head` eyebrow styling is now scoped only to the left-side eyebrow span, so action/status badges are not forced uppercase or enlarged.
- Removed page-specific badge sizing overrides from project cards and Gaming family/category labels so they inherit the global badge standard.
- Existing semantic tones (`neutral`, `success`, `warning`, `danger`, `info`) and Gaming category colors are preserved.

## No contract or data changes

- No D1 migration.
- No Worker route changes.
- No payment/funding behavior changes.
- No contract release change.

# NEXT F CMS V1.0.38 — Global Modal & Form Layout

This release normalizes the shared CMS modal and form-grid behavior without changing business logic, APIs, contracts, D1 schema, checkout behavior, supplier behavior, or finance calculations.

## Changes

- Standard editor modals use a wider 640px working width; confirmations remain compact.
- Modal height is constrained to the viewport and only the body scrolls, keeping headers and footer actions stable.
- Two-column form grids align fields to the start, preventing short inputs from stretching to the height of a taller neighboring field.
- Existing in-body `modal-actions` rows receive the same visual footer treatment as newer `footer`-prop dialogs.
- Long help-center textarea fields may span both columns inside two-column modal forms.
- Mobile dialogs use viewport-safe sizing and flexible action buttons.
- Opening a modal locks page scrolling and restores it on close.
- Dialog title/description IDs are unique per modal instance for accessibility.

## Scope audit

The regression check audits all shared `Modal` and `ConfirmDialog` usages in the CMS and verifies the centralized shell rules. Specialist wide dialogs such as the Gaming product editor and Promotions builder retain their explicit layouts.

# CMS v1.0.23 — Global UI system + storefront connection

## Scope

Frontend-only P4 hotfix that standardizes high-frequency native browser controls and corrects the production Gaming storefront destination.

## Changes

- Theme-aware scrollbars across WebKit/Chromium and Firefox.
- Custom global checkbox/tick states with keyboard focus, indeterminate, disabled and checked visuals.
- Reusable Gaming category badges with distinct semantic colors for top-ups, game keys, gift cards, Steam, Telegram, subscriptions and services.
- Catalog product-kind labels now use the category badge system.
- Game-family derived categories use the same badge system.
- `VITE_GAMING_STOREFRONT_URL=https://gaming.nextf.lk` is part of the non-secret production frontend configuration.
- `gaming.public-storefront` resolves as connected only when a valid HTTPS production storefront URL is configured.
- Catalog and Storefront Merchandising open the configured production storefront.
- The embedded CMS storefront simulator remains restricted to local prototype mode.

## Deployment

Frontend only. No Worker/API deployment, D1 migration, or new secret is required.

# NEXT F CMS v1.0.47 — Storefront Carousel + Verified Reviews

- Mixed image/video hero carousel editor, maximum five slides, with legacy hero fallback.
- NEXT F Media video uploads for MP4/WebM (50 MiB cap) and HTTP byte-range serving.
- Game-family artwork workspace uses a bounded desktop scroller with a sticky filter toolbar.
- New Customer Reviews moderation workspace: pending verified-purchase reviews can be approved or rejected. Approved reviews become publicly available automatically through the Gaming API.
- CMS → Gaming review decisions use a separate deterministic idempotency namespace because both Workers share the production idempotency table.
- No D1 migration required.

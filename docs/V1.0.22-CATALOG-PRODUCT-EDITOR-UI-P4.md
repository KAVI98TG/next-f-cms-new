# CMS v1.0.22 — Catalog product-editor UI refresh

This frontend-only P4 hotfix restructures the canonical NEXT F product editor for faster merchandising work.

- Wider bounded modal with independent scrolling body and anchored action footer.
- Customer-facing identity fields grouped separately from supplier source context.
- Artwork upload and preview moved into a dedicated media panel.
- Preview reduced to a compact 16:9 presentation instead of consuming most of the dialog height.
- Responsive one-column layout on narrower screens.
- No API, D1 schema, Gaming Worker, or public storefront contract changes.

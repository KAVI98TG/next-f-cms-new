# V0.5.0 Gaming Store Core

## Purpose
Build the Gaming Store as a focused supplier-reseller operations system, not a generic e-commerce ERP.

## Core boundaries

```text
Supplier source data
       ↓
NEXT F mapping layer
       ↓
Pricing safeguards
       ↓
Storefront product
       ↓
Order + payment state
       ↓
Supplier fulfillment state
       ↓
Reconciliation / support
```

Supplier offers and NEXT F products are separate records. This allows NEXT F to rename products, set its own prices, pause items, change suppliers later and preserve order history independently of a provider.

## Implemented modules
- Dashboard
- Orders
- Products
- Pricing
- Suppliers
- Customers
- Finance
- Support
- Settings

## Deferred adapters
Real supplier HTTP calls, credentials, supplier webhooks, payment gateway and Cloudflare runtime will replace the current local adapters during the final infrastructure phase.
